# Raivon: Territory Wars

Мобильная вертикальная PvE-стратегия завоеваний на гекс-карте для Android и iOS. Маленькое синее государство растёт до огромной державы через короткие войны в реальном времени, мирные договоры и экономику.

**Главная фишка.** Во время войны захваченные гексы только **оккупированы**: толстый контур официальной границы стоит на месте. Когда стороны подписывают **мирный договор**, контур плавно перетекает на новые гексы. Это центральный «вау-момент» игры.

> **Статус (v0.8.0):** играбельные главы I–II (Долина и Речной край) в 3D на Godot 4: война и мир с церемонией, экономика, обозы, исследования, эволюция облика по УР 1–8, обучение, Лавка с кейсами, звук и музыка, сохранение. Рынок, марши армий, башни, лагеря мародёров, разорение и ремонт. Сервер v0.1 (гостевой вход, облачные сохранения). Сборки Android/iOS — GitHub Actions «Mobile builds». Журнал — [`docs/dev/dev_log.md`](docs/dev/dev_log.md), план — [`docs/dev/backlog.md`](docs/dev/backlog.md).

5. [`docs/testing_on_devices.md`](docs/testing_on_devices.md) — как ставить тестовые сборки на iPhone и Android.

## Ключевые решения в одном экране

| Тема | Решение |
|---|---|
| Режимы | PvE-кампания против ИИ-государств. PvP — только отдельный асинхронный режим «Арена Рубежей», на карту и границы не влияет |
| Темп | Реальное время, как в Clash of Clans: таймеры экономики + наступления по 90 с прямо на карте. Карты войны тратят энергию (старт 5, максимум 10, +1 за 3 с) |
| Мир | Чем выше военный счёт, тем больше требований: гексы, золото, репарации, право на разграбление. ИИ всегда соглашается, если требования укладываются в счёт |
| Поражение | Государство нельзя потерять: Ядро (столица + 6 соседей) неприкосновенно у всех. Проигравший отдаёт часть земли, победитель грабит 30/45/60%. Потолок потерь у всех; прогресс (уровни, технологии) не теряется никогда |
| Развитие | 10 уровней державы, у каждого свой облик: плетень → ультразабор, халупы → небоскрёбы, ополченцы → мехи. Апкип растёт от ×1 до ×70 |
| Мир игры | Один растущий мир: главы 50 → 90 → 160 → 250 → 360 → 500 гексов. На запуске главы I–IV |
| Монетизация | 50/50 реклама + покупки (по общей выручке). Кейсы, лутбоксы, паки и косметика обязательны и одинаковы во всех странах. В России платежи отключены |
| Разработка | ИИ-агент (Claude Code): клиент Godot 4 (GDScript), 3D-модели — Blender-скрипты (bpy), сервер Node.js (Fastify) + PostgreSQL; правила игры одни и те же на клиенте и сервере (headless Godot). Обложки сторов и экраны загрузки — Blender-рендер или ChatGPT |
| Инфраструктура | $100/мес на старте, горизонтальное масштабирование |

## Целевые KPI на запуске

D1 / D7 / D30 — 40% / 16% / 7%; 5 сессий в день по ~6 минут; ARPDAU $0,08; реклама / покупки ≈ 50 / 50 (канон §17).
