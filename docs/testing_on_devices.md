# Как тестировать Raivon на телефоне

> Инструкция для владельца. Клиент — Godot 4.5.1 (папка `game/`), 3D-модели из Blender. Одна кодовая база собирается под Android и iOS.

## Android (Samsung S25 Ultra) — самый быстрый путь

1. Открой на телефоне файл `builds/raivon-debug.apk` из репозитория (GitHub → ветка `claude/funny-maxwell-5e3vez` → `builds` → `raivon-debug.apk` → Download).
2. Разреши установку из этого источника (Chrome/Файлы → «Разрешить»).
3. Установи. Новая версия ставится поверх старой; прогресс сохраняется на устройстве.
4. Начать заново: шестерёнка → «Новая игра (удерживайте)».

APK пересобирается на каждой заметной вехе, версия видна в настройках игры.

## iPhone (iPhone 18 Pro Max) через MacBook — бесплатно

Один раз:
1. Установи **Xcode** из Mac App Store.
2. Xcode → Settings → Accounts → «+» → добавь свой Apple ID (подойдёт обычный бесплатный).
3. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).

Каждая версия:
1. GitHub → репозиторий Raivon → вкладка **Actions** → «iOS Xcode project» → последний зелёный запуск → внизу **Artifacts** → скачай `Raivon-ios-xcode` (zip). Если артефакта нет или он старше 7 дней — нажми «Run workflow» справа вверху и подожди ~10 мин.
2. Распакуй, открой `ios/Raivon.xcodeproj` в Xcode.
3. Слева проект **Raivon** → вкладка **Signing & Capabilities** → Team: выбери свой Apple ID (Personal Team). Если ругается на Bundle Identifier — допиши к нему что-нибудь своё, например `.kaboomenko`.
4. Подключи iPhone кабелем, выбери его вверху окна Xcode и нажми **▶ Run**.
5. Первый запуск: на iPhone Настройки → Основные → VPN и управление устройством → твой Apple ID → **Доверять**.

С бесплатным Apple ID установка работает 7 дней, потом повтори шаг 4.

## TestFlight (для закрытого теста)

1. Регистрация в **Apple Developer Program** как физлицо ($99/год; проверка личности — несколько дней, лучше начать заранее).
2. Я добавлю в GitHub Actions подпись и загрузку в TestFlight; от тебя понадобится ключ App Store Connect API (пришлю пошаговую инструкцию на этом этапе).
3. На iPhone — приложение **TestFlight**, новые сборки приходят сами.

## Google Play (для закрытого теста)

Для личного аккаунта Google требует закрытый тест: не меньше 12 тестеров 14 дней подряд (решение 26). Внутренний трек — для тебя и пары друзей без ожидания.

## Что проверять

- Обучение: советник ведёт через первую войну (объявить → наступление 60 с → мир → церемония).
- Бой: тянуть пальцем от своей армии на соседний вражеский гекс; карты снизу — перетаскивать на гекс.
- Экономика: монеты над гексами (тап — «Собрать всё»), вкладка «Здания» — улучшения с таймерами.
- Через ~2 ч после первого мира Бароны пришлют ультиматум.
- Ошибки и впечатления — в чат: что делал → что ожидал → что произошло, плюс скриншот или запись экрана.
