# Как тестировать Raivon на телефоне

> Инструкция для владельца. Игра пишется на TypeScript + PixiJS и упаковывается в приложение через Capacitor (`docs/gdd/12_tech_analytics_roadmap.md`). Поэтому одна и та же сборка работает и как веб-страница, и как приложение iOS/Android.

## Какой способ когда

| Способ | Что нужно | Когда использовать | Ограничения |
|---|---|---|---|
| **1. Веб-версия в Safari** | только iPhone и ссылка | первый прототип: проверить управление, бой, церемонию мира | нет покупок, рекламы и пушей; нужен интернет |
| **2. Сборка через Xcode на MacBook** | MacBook, Xcode, кабель, бесплатный Apple ID | проверить «настоящее» приложение до покупки аккаунта разработчика | приложение перестаёт запускаться через 7 дней, его нужно переустановить |
| **3. TestFlight** | Apple Developer Program ($99/год) | вертикальный срез, MVP, закрытый тест | первая внешняя сборка проходит бета-ревью Apple (обычно до суток) |
| **Android: APK** | Samsung S25 Ultra | любой этап | — |

## 1. Веб-версия в Safari (самый быстрый путь)

1. Я присылаю ссылку на сборку прототипа.
2. Открой ссылку на iPhone в **Safari**.
3. Для полноэкранного режима: кнопка «Поделиться» → **«На экран „Домой“»**. Игра откроется с иконки без адресной строки, как приложение.
4. Обновления приходят сами: перезапусти игру с иконки.

## 2. Сборка на iPhone через Xcode (бесплатно)

Один раз:
1. Установи **Xcode** из Mac App Store (≈15 ГБ). Затем в Терминале: `xcode-select --install`.
2. Установи **Node.js LTS** (с nodejs.org) и **Git**.
3. Xcode → Settings → Accounts → «+» → добавь свой Apple ID (подойдёт обычный, бесплатный).
4. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).

Каждая сборка:
```bash
git clone https://github.com/kaboomenko/Raivon.git   # первый раз; потом: git pull
cd Raivon
npm ci
npm run build
npx cap sync ios
npx cap open ios          # откроется Xcode
```
5. В Xcode: слева проект **App** → Signing & Capabilities → Team: выбери свой Apple ID (Personal Team). Если ругается на Bundle Identifier — допиши к нему что-нибудь своё, например `.kaboomenko`.
6. Подключи iPhone кабелем, выбери его вверху окна Xcode и нажми **▶ Run**.
7. Первый запуск: на iPhone Настройки → Основные → VPN и управление устройством → твой Apple ID → **Доверять**.

С бесплатным Apple ID сборка работает 7 дней, дальше повтори шаг 6. Команды выше можно поручить Claude Code, запущенному прямо на MacBook.

## 3. TestFlight (для среза, MVP и закрытого теста)

1. Зарегистрируйся в **Apple Developer Program** как физлицо (developer.apple.com/programs, $99/год). Проверка личности занимает от нескольких дней — лучше начать заранее.
2. Я настраиваю сборку в GitHub Actions: каждая версия сама собирается и загружается в TestFlight. От тебя нужен ключ App Store Connect API (инструкцию пришлю на этом этапе).
3. На iPhone поставь приложение **TestFlight** из App Store и прими приглашение. Новые сборки приходят автоматически.
4. Внутренние тестеры (до 100 человек с доступом к аккаунту) — без ревью Apple. Внешние (до 10 000, закрытый тест) — после бета-ревью первой сборки.

## Android (Samsung S25 Ultra)

- **Быстро:** я присылаю ссылку на `.apk` → открыть на телефоне → разрешить установку из этого источника → установить.
- **Для закрытого теста:** внутренний и закрытый треки Google Play. Для личного аккаунта Google требует перед публикацией закрытый тест: не меньше 12 тестеров 14 дней подряд (`docs/00_brief.md`, решение 26).

## Что проверять и как сообщать

- Каждая сборка приходит с коротким чек-листом: что изменилось и что проверить.
- Ошибки и впечатления — в чат: что делал → что ожидал → что произошло, плюс скриншот или запись экрана.
- В прототипе главное — понятно ли управление без подсказок и приятен ли момент подписания мира.
