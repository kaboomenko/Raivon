# Открытые вопросы по игре

> Журнал вопросов к владельцу продукта. Каждый вопрос задаётся в чате, сюда записывается для памяти.
> Пока ответа нет, в GDD принят **вариант по умолчанию**. Когда ответ получен, статус меняется на ✅ и правится GDD.

| # | Вопрос | Вариант по умолчанию / ответ | Статус |
|---|--------|-------------------------------------|--------|
| Q1 | **PvE или PvP?** | ✅ **Ответ:** Основа — PvE. Сражения с живыми игроками только в отдельном режиме. | ✅ отвечено |
| Q2 | **Сеттинг и эпоха.** | ✅ **Ответ:** Оружие, укрепления и постройки улучшаются вместе с развитием государства: заборы → «ультразаборы», халупы → небоскрёбы. Чем выше уровень, тем дороже обслуживание. | ✅ отвечено |
| Q3 | **Темп войны.** | ✅ **Ответ:** Реальное время, как в Clash of Clans. | ✅ отвечено |
| Q4 | **Онлайн/офлайн.** | ✅ **Ответ:** Только онлайн. | ✅ отвечено |
| Q5 | **ЦА, возраст и регионы запуска.** | ✅ **Ответ:** Возраст по умолчанию (12+), запуск сразу по всему миру. | ✅ отвечено |
| Q6 | **Команда, движок, сроки MVP.** | ✅ **Ответ:** Игру разрабатывает ИИ-агент (Claude Code), а не люди. Стек выбирается под эту модель разработки. | ✅ отвечено |
| Q7 | **Командиры/герои и случайные награды.** | ✅ **Ответ:** Кейсы, лутбоксы, паки, визуалы и косметика **обязательны во всех странах; удалять или заменять их нельзя ни при каких условиях.** | ✅ отвечено |
| Q8 | **Можно ли потерять всё государство?** | ✅ **Ответ:** Нельзя. При поражении часть территории отходит противнику, и он может разграбить незавоёванные территории на 30–60%. | ✅ отвечено |
| Q9 | **Уточнение к Q1.** «Сражения только в отдельном режиме» значит, что PvP с живыми игроками вынесен в отдельный режим (арена/рейды) и не влияет на PvE-карту и границы? | Да: PvP — отдельный асинхронный режим (атака на сохранённую оборону другого игрока), рейтинг и награды; PvE-карта у каждого своя. | ⏳ ждёт ответа |
| Q10 | **Графика и звук.** В этом окружении я не могу рисовать растровый арт. Кто делает арт? | Для прототипа — моя стилизованная векторная/процедурная графика. Финальный арт — ты генерируешь в ИИ-генераторе по моим промптам и списку ассетов; либо даёшь мне доступ к API генерации картинок. | ⏳ ждёт ответа |
| Q11 | **Аккаунты и публикация.** Google Play Console, Apple Developer, рекламные сети, платёжные данные — всё оформляется на тебя. Для сборок iOS нужен macOS (можно GitHub Actions). | Аккаунты заводишь ты, я настраиваю CI/CD-сборки и интеграции. | ⏳ ждёт ответа |
| Q12 | **Разграбление 30–60%.** Это доля ресурсов на складах незавоёванных территорий (как добыча в CoC) или временное падение их производства? Работает ли так же, когда побеждает игрок? | Это ресурсы со складов, кроме защищённой доли, плюс временное «разорение» (−производство на несколько часов). Правило симметрично: победивший игрок тоже может грабить. | ⏳ ждёт ответа |
| Q13 | **Бюджет на серверы и сервисы** до выхода на окупаемость? | Старт ~$50–150/мес, масштабирование по мере роста. | ⏳ ждёт ответа |
| Q14 | **Лутбоксы в странах с запретом на платные лутбоксы** (Бельгия; Бразилия — для игр, доступных несовершеннолетним). Лутбоксы остаются в игре в любом случае. Вопрос только в способе открытия в этих странах. | Кейсы есть везде. В этих странах их открывают игровыми ключами (за игру, рекламу, события), а не прямой покупкой за деньги; паки и косметика продаются как обычно. Альтернатива — одинаково везде, на риск владельца. | ⏳ ждёт ответа |
