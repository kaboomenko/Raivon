# Сервер Raivon (v0.1)

Код: `apps/server` (Fastify + PostgreSQL 16, TypeScript, запуск через `tsx`). Спецификация — `docs/gdd/12_tech_analytics_roadmap.md` §6–8; сейчас реализован первый срез.

## Что умеет
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/healthz` | живость |
| GET | `/v1/bootstrap` | время сервера, минимальная версия клиента, флаги (`alliances: false` — решение 24), `payments` по стране стора (RU → только реклама, решение 16) |
| POST | `/v1/auth/guest` `{device_id}` | гостевой аккаунт по id устройства → JWT на 30 дней |
| GET | `/v1/save` | облачное сохранение `{rev, saved_at, data}` |
| PUT | `/v1/save` `{base_rev, data}` | запись с оптимистичной блокировкой: 409 при чужой ревизии; проверка формы сохранения (версия, сид, клетки, ресурсы ≥ 0, ≤ 512 КБ) |

## Запуск
- Разработка: `npm run dev -w @raivon/server` (без `DATABASE_URL` — хранилище в памяти).
- Тесты: `npx vitest run --root apps/server`; с настоящим PostgreSQL: `TEST_DATABASE_URL=postgres://… npx vitest run --root apps/server`.
- Прод (один VPS, ~5–10 €/мес): `cd apps/server && cp .env.example .env` (задать `JWT_SECRET` ≥ 32 символов и `PGPASSWORD`) → `docker compose up -d`. Перед API — Cloudflare (бесплатный план): TLS, WAF, заголовок `CF-IPCountry`.

## Решение: как делать авторитетность (2026-10-05)
Канон (`12` §4) предполагал общий TS-модуль `sim` для клиента и сервера. Клиент теперь на Godot, правила (бой, война, экономика, залежи, исследования, кейсы) живут в `game/scripts/sim/*.gd`. Чтобы не держать две реализации, сервер будет запускать **тот же GDScript** в пуле headless-процессов Godot («sim worker», ~50 МБ ОЗУ каждый): API (Node) передаёт им JSON-команды по stdin/stdout, воркер применяет их к снимку мира и возвращает новый снимок и события. Детерминизм уже проверяется тестами (`game/tests`), паритет боя с TS-версией — `test_sim.gd`.

Порядок работ:
1. Клиент: модуль `net.gd` — гостевой вход, загрузка/выгрузка сохранения, серверное время вместо часов устройства.
2. Воркер: `game/server/sim_worker.gd` (headless, без рендера) с командами `collect`, `upgrade`, `research`, `colonize`, `convoy`, `open_case`, `battle_verify` (перепроверка лога боя).
3. API переходит с «сохранение целиком» на команды; сохранение клиента становится кешем.
