# Бэклог автономной разработки

Правило: сверху — самое важное. Каждая задача доводится до рабочего состояния с проверкой скриншотом. Ориентир внешнего вида — `docs/art_direction.md`, правила — `docs/gdd/00_canon.md`.

## Сейчас
- [x] **Камера и ввод:** перетаскивание карты пальцем, масштаб щипком/колёсиком с плавным переходом «стратегия ↔ близко», границы камеры, инерция.
- [x] **Выбор гекса:** тап по гексу → подсветка и панель справа внизу (тип, владелец, бонус), кнопка «Атаковать» активна у вражеских гексов на фронте.
- [x] **Данные карты в GDScript:** перенести генератор главы I и типы гексов из `packages/sim` (владелец/контроль, ценность, ядро), карта главы вместо декоративной.
- [x] **Война v1 в 3D:** объявление войны, наступление 90 с: отряды выдвигаются на вражеский гекс, бой (формула канона §9.5), энергия и карты как заклинания, оккупация (штриховка + знамёна), военный счёт и шкала контроля.
- [x] **Мир и церемония в 3D:** мирная конференция (пергамент), печать, неоновая граница «перетекает» на новые гексы волной, заливка меняет цвет, счётчики.
