# Как запускать (для автономной разработки)

1. `tools/setup_env.sh` — восстановить инструменты в новом контейнере (Godot 4.5.1, Blender bpy 5.0.1, Xvfb + Mesa lavapipe, npm).
2. Модели: `python3 tools/blender/export_assets.py game/assets/models [имя ...]` → `.glb` для Godot.
3. Импорт в Godot: `flock -w 1800 /tmp/raivon_godot.lock /opt/godot/Godot_v4.5.1-stable_linux.x86_64 --headless --path game --import` (тот же замок, что у `godot_shot.sh`: импорт не столкнётся со съёмкой).
4. Скриншот клиента: `tools/godot_shot.sh /путь/out.png [--forward-plus] [--res=WxH] [--zoom=0.15] [--focus=q,r[,zoom]] [--dl=N] [--ai-dl=N]` (941×1672, как эталон; `--res=941x2040` — высокий телефон: холст растягивается в высоту, нижняя группа HUD уезжает вниз по безопасной зоне — так проверяется каждый экран, `docs/ui_style.md` §3.1). По умолчанию — Mobile-рендерер, как на телефонах; печатает `perf draw_calls=… objects=… primitives=…`, а также `SCRIPT ERROR`, `SHADER ERROR` и строку шейдера с ошибкой (шейдер, который не собрался, рисуется невидимым). Запуски godot идут по очереди через замок `/tmp/raivon_godot.lock`; если замок не дождался (30 мин), godot превысил 5 мин (15 мин с `--perf-tree`) или снимок не сохранился, печатается `godot_shot: ERROR: …` (код выхода всё равно 0). Сохранив снимок, игра сама завершает свой процесс (`OS.kill`): обычный выход под xvfb + lavapipe иногда зависал в разборке рендерера и держал замок до лимита. `--fixed-fps=N` уходит движку: каждый кадр продвигает игровое время ровно на 1/N с, и анимация ловится в одном и том же моменте при любой загрузке машины (с `--shot-delay` это дорого: N кадров на секунду задержки).
4b. Стандартный набор кадров «Raivon Soft» (art_direction §6.12): `tools/soft_shots.sh OUTDIR [strat z03 close dl8 cer sel battle]` → `OUTDIR/<набор>.png`, `.log`, `metrics.txt`. Замер облика: `python3 -I tools/look_metrics.py IMG… [--check] [--sample x0,y0,x1,y1] [--gray OUT.png] [--deutan OUT.png]` — яркость, чернота, «раскалённо-белое», зерно, резкие перепады, L*, медиана травы; `--check` перечисляет промахи по целям §6.12.
4c. Интерфейс (`docs/ui_style.md` — дизайн-система): шрифты лежат в `game/assets/fonts/` — `Rubik-VF.ttf`, `Nunito-VF.ttf` (переменные, SIL OFL 1.1, лицензии `OFL-Rubik.txt`, `OFL-Nunito.txt`) и ресурсы FontVariation `display_900.tres` / `display_800.tres` / `body_800.tres` (через `Kit.font("d900"|"d800"|"b800")`; после замены шрифта нужен импорт, п. 3). Токены и компоненты — `game/scripts/ui_kit.gd` (`const Kit := preload(...)`). Линтер UI: `python3 tools/ui_lint.py [--strict]` — правила R1–R7 §8.1 (литералы `Color(` в UI, кегли вне шкалы, радиусы, пиктограммы в `strings.csv` и строках `.gd`, мягкие тени, `modulate.a` как «выключено»); без флага — отчёт, с `--strict` — код выхода 1 при любой находке (так он идёт в CI рядом с `tools/check_strings.py`). Полный набор кадров для проверки интерфейса — `docs/ui_style.md` §8.2.
5. Проверка GDScript: `godot --headless --path game --check-only --script res://scripts/<file>.gd`.
5b. Тест игрового цикла: `godot --headless --path game --script res://tests/test_flow.gd`. Демо-состояния для скриншотов: `tools/godot_shot.sh OUT.png --demo=battle:40|result|peace|ceremony:1.5`. Церемония идёт и во время `--shot-delay`, и к 4-й секунде её закрывает окно итогов; середина церемонии без окна — `--fixed-fps=6 --demo=ceremony:0.15` без задержки (набор cer). Демо глав (`ch2:<вид>`, `ch3:<вид>`, `ch4:<биом>`, `oil`, `swap`, `dip2`…) сначала проигрывают одно–три расширения мира (~7 с каждое): снимок ждёт конца демо и после него ещё `--shot-delay` (не меньше 1.5 с: подлёт камеры, запекание панели гекса; раньше получался обзор мира посреди расширения), а `--zoom=` применяется после фокуса демо — `--demo=ch2:dark_lake --zoom=0.12` даёт тёмное озеро вблизи.
6. APK для Android: `cd game && godot --headless --path . --export-debug "Android" ../builds/raivon-debug.apk` (arm64, подпись отладочным ключом). APK в git не коммитится (большой): для владельца его собирает GitHub Actions «Mobile builds» при смене версии в `export_presets.cfg` (артефакты Android APK и проект Xcode).
7. Старый веб-прототип (`apps/client`, `packages/sim`) — только как справочник правил; `npm test` гоняет тесты sim.

Особенности: видеокарты нет, рендер программный (lavapipe) — кадр 941×1672 рендерится ~30 с. Сайты с CC0-моделями заблокированы сетевой политикой окружения.
